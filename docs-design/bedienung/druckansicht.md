# Druckansicht im Design

Ab Version 1.1.0 übernimmt auch die **Druckansicht der Objektlisten** Ihr Design.
Sie öffnen sie wie gewohnt über das Drucker-Symbol oben rechts in einer
Objektliste — es erscheint ein eigenes Fenster mit einer druckfreundlichen
Aufbereitung der gewählten Objekte.

## Was übernommen wird

Die Grundfläche bleibt bewusst weiß (Papier!), Ihr Design setzt die Akzente:

| Element der Druckansicht | Übernimmt |
|---|---|
| Logo im Kopfbereich | Ihr hochgeladenes **Logo** (samt Logo-Hintergrundfarbe) |
| Trennlinie und Objekt-Titelzeilen | Farbe und Schriftfarbe der **Navigation** |
| Kategorie-Titelzeilen | Farbe der **aktiven Navigation** |
| Tabellenköpfe | Farbe und Schriftfarbe der **Schaltflächen** |

Die Farben werden so ausgezeichnet, dass sie auch beim tatsächlichen Ausdruck
erhalten bleiben (nicht nur in der Bildschirm-Vorschau).

## Voraussetzungen und Grenzen

- Die Druckansicht verwendet den Stand des zuletzt **angewendeten** Designs.
  Nach Änderungen also einmal **Design anwenden** klicken.
- Ist kein Design aktiv, zeigt die Druckansicht das i-doit-Standardlayout.
- **Firefox** stellt die Druckansicht von i-doit generell ohne Formatierung dar —
  das ist eine Einschränkung von i-doit selbst und wird beim Öffnen als Warnung
  eingeblendet. Verwenden Sie für formatierte Ausdrucke Chrome oder Edge.
- Das normale Drucken einer i-doit-Seite mit **Strg + P** ist von diesem Feature
  unberührt und nutzt weiterhin die druckoptimierte Schwarz-Weiß-Darstellung
  von i-doit.
